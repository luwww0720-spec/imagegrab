第一次使用

打开支持的商品详情页，滚动加载详情图片，点击右下角「获取图片」。在新标签页勾选后下载。刚安装插件时，请先刷新已有商品页。

哪些图片可以提取？为什么有时下载失败？ ＋

插件面向淘宝、天猫、京东及拼多多商家商品详情页，提取当前页面中可读取且已加载的图片。平台登录、页面改版、防盗链或未授权的图片域名可能导致提取或下载失败，插件不会绕过访问限制。SVG、GIF 等可解码图片会转为静态 PNG。请只下载你拥有使用权的素材。
